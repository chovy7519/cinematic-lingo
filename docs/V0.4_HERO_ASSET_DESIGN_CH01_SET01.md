# Cinematic Lingo｜主角与摄影棚资产设计包 V1
> 设计归属：AI 美术指导（造型、材质、分镜与验收）  
> 制作归属：Blender 建模（模型、UV、材质、GLB）  
> 性质：可执行的首版设计定稿方向；视觉参考图是概念稿，不是精确 CAD / 拓扑图。  
> 目标：电影摄影专业工具的“静默观察者”，而不是玩具、赛博朋克或虚拟人广告。

## A. 全局视觉原则

品牌已有的 Cinematic Editorial × Architectural Film Set 方向不变。
视觉层级依次为：**真实的摄影机画面 > 清楚的人物形体 > 有秩序的建筑空间 > 简洁的专业 UI**。

画面控制在石墨灰、冷矿物灰、骨白以及极少量氧化铜、黄昏暖光；不使用复古泛黄、霓虹、胶片齿孔、假电影品牌、夸张颗粒、磨皮陶瓷肤质或塑料布料。特写要让人看到皮肤、骨点、眼窝、鼻翼、衣料厚度，而不是靠大颗灯光把人照得发白。

## B. CH-01｜The Observer / 静默观察者（最高优先）

### B1. 角色叙事与气质

不是主角 IP，也不承担戏剧表演。是进入建筑摄影棚的一个普通成年观察者：独立、沉静、略有内向感，姿态克制。**重要的是人体与画面的关系，而不是角色的身份故事。**

采用轻风格化写实（soft stylized realism）：
- 解剖关系可靠，比例真实，表面与轮廓适当简化；
- 眼睛不放大，不做玩具圆脸，不做夸张漫画鼻、厚唇或下巴；
- 成人、中性、自然短发，避免“人形假人”“机器人”和明显的特定名人长相；
- 三视图以中性直立姿态为基准；最终展示姿态可做重心略偏一侧、肩高细微不对称、头部轻微转角。

### B2. 统一比例（Blender 中按米建模）

| 设计项 | 建议起点 | 备注 |
|---|---:|---|
| 总高 | **1.82 m** | 不含头发极少量突起，脚底地面 Y=0 |
| 肩宽 | 0.46 m | 含衣服，不是骨架肩宽 |
| 头部高度（头顶至颏） | 0.245 m | 真人成人比例基础 |
| 鞋底长度 | 0.275 m | 视觉上干净不夸张 |
| 姿态 | 中性自然站姿，双臂离躯干约 10–15° | 先对称建模、后制作轻微不对称静态姿态 |
| 原点与朝向 | (0, 0, 0)，**Y 向上、+Z 朝前** | 当前相机在 +Z 一侧观察人物 |
| 世界位置 | 实验室场景原点 (0, 0, 0) | 不平移整套舞台 |

**兼容性注意**：现有程序化替身接近 1.99 m，正式模型将缩为 1.82 m。导入后我方必须重新验收预设取景及注视高度，**不能为了保留旧构图偷偷非等比拉伸 GLB**。

### B3. 头脸与发型

- **面型**：面部长度略长于宽度；额骨、眼窝、眉弓、颧骨、鼻梁—鼻翼和下颌骨形成可信的光影平面。侧视需有真实鼻额角与鼻尖体积。
- **五官**：自然大小、眼窝略深、眼神中性；不夸大瞳孔或添加图标式眉眼；嘴唇闭合、边缘克制。
- **肤色**：低饱和暖灰褐，基础参考色 `#AA8E7B`；真正的肤色以带光渲染校准，不把 Hex 当作精确材质真值。
- **皮肤**：微弱毛孔/细节仅在特写读到，不做高光塑料；可先用 2K normal/roughness，在真实 85mm 取景验证后再决定是否升级。
- **发型**：偏短的层次碎发，发流不完全对称；前额露出，发际线真实。用少量低反射发束与轮廓体块，杜绝整块球壳“头盔发”。
- **面部表情**：neutral；不微笑、不皱眉、不夸张“忧郁”感。作为镜头语言基准模型，情绪留给摄影机与光线。

### B4. 服装造型（不允许自由替换大轮廓）

- **上装**：及臀的简洁结构夹克 / 厚棉斜纹外套，低立领；胸腰衔接自然，肩袖一体读得清楚。**不用宽大的西装翻领或长及脚踝的大衣**。
- **内搭**：灰褐色薄针织或轻薄立领内搭，仅领口露少量，避免胸前出现巨大的明亮三角形。
- **袖子**：袖山真实、肘窝有轻微张力褶皱；袖口无需金属环；手可自然露出，但不要像独立胶囊体。
- **裤装**：深灰直筒偏收脚，膝部有限几道结构褶；不贴腿也不肥大。
- **鞋**：哑光黑灰平底短靴，真实鞋头与鞋帮连接，不能做圆球鞋或长方体鞋。
- **饰品**：不加入包、武器、首饰、耳机、LOGO、腕带、闪亮扣件。
- **背面**：保持一条竖向结构接缝和简洁的肩背折线，不做大面积印花。
- **配色建议**：外套 `#273337`；内搭 `#626B69`；裤子 `#242D31`；鞋 `#171E23`，整体暗值分离依靠 roughness 和光照，不依靠鲜艳撞色。

### B5. PBR 粗糙度设计目标（0–1，须在 Three.js 场景校准）

| 材质槽建议 | Base color 方向 | Roughness 起点 | 备注 |
|---|---|---:|---|
| `M_SKIN_WARM_NEUTRAL` | 暖灰褐 | 0.70–0.83 | 近景需要微法线，但不应起霜或油亮 |
| `M_COAT_GRAPHITE_TWILL` | 石墨灰 | 0.82–0.94 | 织纹、缝线和极轻磨损 |
| `M_SHIRT_COOL_GREY` | 脱饱和灰绿 | 0.86–0.96 | 作为头颈下方的中间明度 |
| `M_HAIR_CHARCOAL` | 深炭灰 | 0.68–0.82 | 区分发束与纯黑发盔 |
| `M_BOOT_MATTE` | 炭黑 | 0.68–0.84 | 保留鞋头体积，勿做镜面皮鞋 |

建议头/脸、衣服分别 2K 基础纹理起步，避免开始就制作无用的 8K 贴图。角色主资产以 **30k–70k triangles 初期预算** 做对照，后续可按真实截图放宽或优化，不把面数当美术质量指标。

### B6. 必须交付的建模检验视图

`CH01_01_Turnaround`：正面、严格正侧、背面；同一比例、正交相机、全身，横向对齐地面；不允许各视图使用不同的人体比例。  
`CH01_02_HeadStudy`：正面、3/4、侧面头像；重点检查眉弓、眼窝、颧骨、鼻翼、下颌的形体。  
`CH01_03_Material`：外套组织/走线、肤质、头发、鞋四组材质近景。  
`CH01_04_CameraTest`：50mm / 6m、50mm / 3m、85mm / 2–3m、24mm / 3m、72mm / 9m 等真实相机取景。

这些视图首先用来**验证设计**，不是一次性需要完成的最终图片数量。第一验收只要求三视图灰模 + 正侧面脸部灰模。

## C. SET-01｜The Threshold / 门槛（第二优先）

### C1. 建筑叙事

一座具有克制的当代建筑语言的电影取景廊道。它不应像豪华酒店、未来巨型基地或影视棚搭建示意。空旷但有明确尺度，空间中有实体厚度、墙缝、反射与暗部层次。

主视觉为：**近处低饱和金属细部 → 中景人物 → 远处暖光矩形门洞**。摄影机移动时要产生清晰的空间视差和遮挡变化，这比增加物件数量更重要。

### C2. 现有场景坐标必须保留的锚点

- 人物：`(0, 0, 0)`；地面：`Y ≈ 0`。
- 后景主立面：`Z ≈ -13.4 m`；高度约 `7 m`；主构图宽度约 `18 m`。
- 暖光内院门洞：中心 X=0，门洞厚度与影子要有实际深度；现有后景门洞约 `4.27 m` 宽、`4.86 m` 高（属于取景建筑空间，不是实际门扇尺寸）。
- 左侧阴影侧翼：X≈-6 m，深度与石材立面层次必须成立。
- 右侧竖向构件：X≈4.65–7.5 m，形成更明亮但不均匀的反射节奏。
- 前景细铜色参照杆：X≈-1.32 m，Z≈+1.08 m，用于推镜与变焦的视差读图。
- 重要：这些位置为现有程序化场景的**几何基线**，允许深化厚度、倒角、细节，不要整体移动导致摄影学演示失效。

### C3. 建筑材质与结构

| 材质 | 视觉性质 | 工艺约束 |
|---|---|---|
| 石灰质混凝土 | 冷中性、轻微斑驳、真实接缝 | PBR roughness 约 0.82–0.95；不要用过强脏污贴图 |
| 灰蓝色矿物石材 | 实体厚度、柔和倒角与受光边 | 大面清洁，接缝比纹理更重要 |
| 氧化铜色金属 | 细窄高光、点状节奏 | 只用于细杆/收边，不可大面积铺铜 |
| 中庭浅暖色石材 | 暖光反射、舒缓的景深尽端 | 不做发光纯白矩形，保留明暗渐变 |

可用 0.01–0.035 m 的可见边倒角作为初始白模验证；并非对全部构件套用同一固定工程尺寸。

### C4. 布光逻辑

与现有 `js/studio-set.js` 一致：暖主光从画面左前上方（当前约 -4.5, 8, 4.5），右前方冷补光（5.5, 4.5, 5.4），后方暖轮廓光（1.5, 6.4, -5.7），内院暖反射。避免大片死黑与爆白，让轮廓、地面接触阴影、立面厚度都可辨认。

### C5. 要做成可复用资产而非整块大模型

`SET01_MainWall`、`SET01_Portal`、`SET01_LeftWing`、`SET01_RightFins`、`SET01_ForegroundMarker`、`SET01_Floor`。分体导出便于未来替换、隐藏、独立质检与调整光照；整体的世界原点保持 `(0,0,0)`。

## D. 词典高精度特写资产（由 CH-01 + SET-01 生成）

优先不要另画一张“很电影的美图”来代替科学镜头示意。正确路径是**同一角色/同一场景/统一光色**，在 Blender 里以固定镜头真实渲染三张尺度不同的画面，再作为词典局部视觉素材；确保景别间的人物服装、光方向、空间关系连贯。

- `SHOT01_Wide`：环境是主角，人很小，必须能看清建筑尺度。
- `SHOT02_Medium`：人物成为主信息，但仍保留左右立面和后景景深。
- `SHOT03_CloseUp`：50–85mm 范围内的头肩或脸部构图，五官具有可信体积，背景不喧宾夺主。
- 不将上述截图直接替代所有 SVG 动画；需要在词典层维持运动/构图教学能力的部分继续使用矢量交互。

### 第一轮验收（现在就可以开始）

只制作 **CH-01 的人体白模与服装白模**。通过标准：
1. 正、侧、背三视图人体比例完全一致；
2. 头、肩、袖山、胸腰、膝、脚能在灰模光照下读得清楚；
3. 50mm / 3m 下没有明显“球体头 + 圆柱肢体”拼接感；
4. 在不依赖贴图/后期滤镜的情况下，模型轮廓已经可信；
5. GLB 朝向、单位和轴心符合 +Z 前 / Y 上 / 地面原点。

**暂不制作**表情系统、骨骼动画、LOD、大量场景小道具，也暂不为这套角色生成无用的 8K 贴图。
