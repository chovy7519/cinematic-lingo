# V0.4 · 角色主资产制作与 GLB 交接规范

**状态**：美术开发规范，尚未交付最终 Blender 人物资产。  
**优先级**：P0。现有 `js/character-maquette.js` 是可运行的空间参照替身，不是电影级角色成品。

## 1. 美术验收后的关键决策

自动浏览器截图已证实：单靠 Three.js 基础网格拼接，虽然可以正确教学透视、焦距和相机运动，但人物在近拍时仍出现：
- 脸部像光滑几何蛋形，缺少眼眶、颧骨、颌骨与鼻翼的真实拓扑关系。
- 衣服缺少前胸、袖山、腋下、衣摆和布料张力，肩膀像多边形块体。
- 人物整体缺少可靠的服装重力感；在 50 mm、3 m 的中近景里尤为明显。
- 词典 SVG 在高倍率特写里也暴露出过度抽象的面部插画感。

**结论**：停止把“更真实的人体”继续拆成 SVG/CSS/Three.js 手写零部件。下一步应该是独立 Blender 资产制作，通过 GLB 替换实验室角色，并单独制作词典特写的高分辨率视觉层。目标是两页共享轮廓、服装、色温、材质秩序，但不要求词典所有 SVG 演示转为 WebGL。

## 2. 角色设计 brief

| 参数 | 推荐起点 | 目的 |
|---|---|---|
| 角色类别 | 中性成年人物，现代简约服装，非名人肖像 | 避免人物故事抢走摄影知识重点 |
| 轮廓 | 头颈、肩袖、腰臀、手臂、裤腿与鞋具有连续可读的人体比例 | 改善中近景与低机位阅读 |
| 视觉材料 | 石墨灰、低反射厚棉/羊毛、灰褐色哑光肤色 | 与建筑/摄影实验室统一 |
| 服装 | 结构清晰的短大衣或中长夹克、简洁裤装 | 衣褶服务体积与光照，不叠加饰品 |
| 面部 | 真实拓扑面型 + 克制表情，眼鼻唇有体块但不夸张 | 通过 50 mm 和 85 mm 检查近景 |
| 发型 | 低反射、轮廓清楚；不采用单一半球帽 | 避免玩具化 |
| 姿态 | 自然立姿，肩部微不对称，双臂微离身体 | 既保证尺度参考，又消除机械 A 字 |
| 场景关系 | 角色底部原点在地面，面朝 +Z，中心 X=0 / Z=0 | 兼容现有三个摄影机实验 |

建议全高 **1.75–1.85 m**，头部高度（下巴至头顶） **0.23–0.27 m**，肩宽 **0.42–0.52 m**。这是供首版建模使用的目标区间，不是既有程序化替身的实测尺寸，也不是职业人体参数的唯一标准。

## 3. Blender 的制作流程

1. **白模体块**：先整体人体比例，再做衣服体块。用正交正/侧视检查头肩比、肩袖连接、膝和脚形。先审 silhouette 再审材质。
2. **中高模雕刻**：面部至少明确额骨、眼窝、鼻梁/鼻翼、颧骨、下颌；衣服明确袖山、胸前拉伸、肘部和膝部的褶皱力线。避免堆碎褶。
3. **游戏用网格**：低模目标可以从 **20k–50k triangles** 试做（需实际测得），轮廓与面部优先；不把三角面预算当硬性质量标准。模型命名/材质槽在导出前固定。
4. **UV 与烘焙**：一套或分开的 2K 贴图，包括 base color、normal、roughness；不必为了 Demo 先做 4K/8K。保留 UV 与法线烘焙验证图。
5. **PBR 质感**：主要由布料粗糙度、法线、微褶与关键光决定；皮肤不能使用无细节的高光塑料，也不要覆盖颗粒滤镜冒充材质。
6. **导出 GLB**：`assets/characters/protagonist-v01.glb`，米为单位、Y 向上、正面朝向 +Z、脚底中心在原点、变换应用；保留 Blender 源文件单独归档（例如 `assets-source/protagonist-v01.blend`，不强制把大文件直接纳入 Git）。
7. **集成**：以角色根节点替换 `createCharacter()` 创建的占位组，原 `scene`、摄像机 preset、A/B 截图、建筑位置不改。GLB 加载失败时可以使用现有程序化替身作为降级路径。

> 当前仓库尚未包含该 GLB，也没有宣称它已经制作完毕。不要将现有 `character-maquette.js` 改名伪装为 Blender 建模成果。

## 4. 电影美术验收镜头（必须有截图）

| 机位 | 测试内容 | 不通过的典型表现 |
|---|---|---|
| 正面全身：约 50 mm / 6 m | 全身比例和人与建筑的尺度、投影接触 | 人物过大、鞋浮地、肩袖不连贯 |
| 中近景：约 50 mm / 3 m | 头颈、胸前结构、服装阴影的连续性 | 脸像球、胸前贴平面、衣服出现过分简化的多边形 |
| 特写：约 85 mm / 2–3 m，重新对焦头部 | 面部结构、头发轮廓、鼻翼/眼窝关系 | 贴纸五官、黑色头盔、肤质像塑料 |
| 高/低机位 A/B | 俯仰改变的轮廓与透视 | 角度变化导致模型穿插、破面、腿脚分离 |
| 24 mm 近 / 72 mm 远 | 视差教学准确性 | 为求好看改动世界尺寸或摄影机投影数学 |
| 手机窄屏 | 取景画面可辨认，控制面板不遮住主体 | 画面占比过小或文字与图像对比失衡 |

不能用 CI 通过来替代美术签核；必须比较原始截图、真实 WebGL 画面和用户主观审美反馈。

## 5. 版权和外部素材

优先制作原创人物模型。若使用第三方 CC0 网格作为 Blender sculpt base，需逐个核对资产页的许可、来源及是否包含来自其他人的非 CC0 动作/纹理，不要根据站点总标题直接认定每个组成部分都无需授权。

可查阅的 CC0 雕塑拓扑参考：<https://polyhaven.com/a/marble_bust_01>（Rico Cilliers）。该模型属于古典肖像雕塑，**仅适合作为结构与材质参考**，不宜直接当作本项目现代人物。
