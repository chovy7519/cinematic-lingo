# V0.2 · 46 个术语的知识与教学审校

> **版本说明（2026-11-10）**：此文档记录 V0.2 的术语审校过程，涉及的四道辨析练习已在 V0.2.1 按用户反馈取消；当前产品只保留可视化词典、术语标签和 3D 摄影机实验室。历史判断与审校记录仍然有效。


审校日期：2026-11-10  
审校范围：6 个分类中的全部 46 个术语，逐条阅读了 `plain / note / use / mood / caution`，并检查其演示逻辑所表达的物理含义。  
审校性质：**产品团队的首轮资料核对，不等于影视院校或职业摄影指导的专家最终签核。**

## 结论与准则

- **先界定事实，再讨论表达**：定义与摄影机物理运动、镜头参数、构图结构、照明方式和剪辑操作直接对应；情绪与叙事意义只描述常见可能性。
- **章节 ≠ 互斥学科分类**：保留原有六章便于新手浏览，同时增加知识维度标签。尤其 `OTS`（人物关系）和 `POV`（叙事视点）虽然放在“机位角度”章节，实则不属于俯仰角度。
- **区分二维演示与三维摄影**：原 SVG 动画帮助初学者识别变化方向，但 `viewBox` 变化无法完整产生摄影机位移带来的真实视差；真实空间关系请看独立三维摄影机实验室。
- **不把术语阈值当公式**：近景、特写、全景和鸟瞰在不同电影教材有不同细分标准；应优先看主体、环境、视角和叙事功能，而不是一个硬性的身体裁切百分比。
- **版权审慎**：本阶段不擅自嵌入商业电影片段；下一版若使用案例，需要获得许可或使用自制素材。

## 逐项审校记录

“核对”表示当前核心解释可作为入门示意，但可能仍有教学措辞简化；“修订”表示 V0.2 已调整关键表述；“示意限制”表示演示需要在日后升级时进一步核对。

| 术语 | 知识判断与处置 | 状态 |
|---|---|---|
| 大远景 EWS | 环境主导；删除“人物画高小于四分之一”的固定阈值 | 修订 |
| 远景 WS | 人物全身与环境关系的宽泛类型；区别不是固定比例 | 核对 |
| 全景 FS | 强调人物全身，删除“只要看见脚就是全景” | 修订 |
| 中景 MS | 通常从腰部附近取景，供观察动作与对话 | 核对 |
| 中近景 MCU | 通常兼顾胸肩与表情；不应机械限定裁切线 | 核对 |
| 近景 CS | 中文“近景”和英文 Close Shot 的分级不完全通用；保留现有分类但需注明术语弹性 | 待外部专家校名 |
| 特写 CU | 特写也可以拍物件；修正“可辨认整张脸才算特写”的判据 | 修订 |
| 大特写 ECU | 局部细节拍摄；人物与物件均可成为主体 | 核对 |

## 余留风险（不应包装为已经验证）

1. **英文命名精度**：中文“近景”与 `Close Shot`、`Close-Up` 的分级及“全景”与 `Full Shot` 的对应关系仍需专业电影教材交叉复核。
2. **演示一致性**：特别是摇、移、推、拉、环绕在 SVG 中主要靠取景框变化，不能直接视为真实摄影机位姿。另需对顶拍、OTS 的视觉表现做实机对照。
3. **语义与感受**：卡片的“可能的表达”文本是常见用法，不代表所有镜头中的心理效果。
4. **初学者效果**：四道题属于轻量理解反馈，不是经验证的测评量表；后续可邀新手解释原因，比较观看动画前后的正确率。
5. **外部图像/影片示例**：未来可用自制短片演示真实摄影机操作；商业片段涉及版权与授权。
