# V0.3 双板块深化：设计意图、实现边界与验收

日期：2026-11-10  
状态：实验分支 `feat/v0.3-dictionary-and-camera-lab`，等待本地浏览器验收。

## 定位

继续只维护两个用户板块：

1. **可视化词典 Visual Dictionary**：快速定位一个术语，直接观看动画；有必要时同时观看两个术语的效果。
2. **摄影机实验室 Camera Lab**：从观看镜头画面转向操纵摄影机，理解机位、焦距、空间深度；保留 A/B 画面进行直接比较。

不采用答题、进度、积分、复杂分镜项目管理或未经许可的电影片段。

## 用户任务与实现方案

| 用户任务 | 本轮改进 | 实现位置 |
| --- | --- | --- |
| 我知道一个镜头名，想马上找到它 | 中英文字段、缩写和讲解文字的即时文本匹配；空结果提示； Ctrl/⌘+K 快捷键 | `index.html`、`js/dictionary-tools.js` |
| 我想知道两个概念到底哪里不同 | 每卡一个轻量“加入对照”，选择两项后打开 A/B 双卡动态演示，附定义与提示 | 同上；原 SVG 演示复用 |
| 我想由镜头词典直接试试真实相机 | 推镜、变焦、俯拍、仰拍四张术语卡直接链接到三维实验室对应预设 | `js/dictionary-tools.js`、`js/lab.js` |
| 我想从其他方向看清机位与人物的位置 | 左侧视图可鼠标/触摸拖动、滚轮缩放；键盘方向键及 +/-；一键重置 | `js/lab.js`、`lab.html` |
| 我改了参数，但已经忘了上一次画面什么样 | “记为 A / 记为 B”捕获右侧相机当前画面，参数与画面保留在本次页面内 | 同上 |
| 我在手机或窄屏上使用 | 搜索改为单列；双卡及两张截图在窄屏堆叠；底部对照条折行 | `styles.css`、`lab.html` |

## 交互原则

- **按需展现**：默认词典只增加一个简洁搜索框和卡片对照按钮；完整 A/B 对照在主动选择两条后才出现。
- **继续复用原动画**：对照面板克隆原卡片的 SVG 和现有动画数据，不复制或改写 46 套动画。
- **学习不是考试**：动态演示与事实解释比正确率更重要，取消强制测评是明确的用户反馈。
- **镜头参数有对应关系**：调整观察相机不应影响摄影机的取景。A/B 保存后再改参数，已保存的画面不能被修改。
- **环境开销受控**：Three.js 继续只在独立实验页按需加载；截图数据不上传，也不存到浏览器或服务端。

## 手工浏览器验收脚本

### A：词典查找与并排对照

1. 打开 `index.html`，确认首页仍是原词典且六章数量合计 46 条。
2. 输入 `POV`、`特写`、`Zoom` 和一串不存在的字符，确认结果与无结果提示，并测试清除和 Ctrl/⌘+K。
3. 在“推”与“变焦”上依次点击“加入对照”，再点击底部的“并排观看”。确认两张动画可各自重播。
4. 用“顺光”和“侧光”或“柔光 vs 硬光”替换对照项，确认复制出的光照渐变仍正确运作，原卡也仍正常。
5. 清空后底部条消失。试用手机宽度，确认对照内容上下排列，不遮挡卡片。
6. 从“俯拍”“仰拍”“推”“变焦”任一词条的链接跳往三维实验室，确认跳到匹配的实验/预设。

### B：实验室空间视图与画面对照

1. 在 `lab.html` 加载后，拖动左侧空间视图旋转，滚轮缩放，点击重置恢复初始观察角度。右侧取景在这些操作中保持不变。
2. 使用 `Tab` 聚焦空间视图，方向键改变观察角度、+/- 缩放，检查没有引发页面滚动。
3. 播放推镜 A，结束后保存画面 A；播放变焦 B，结束后保存画面 B。右侧取景应与各自快照一致，两张快照应同时可见。
4. 调整焦距与距离，检查“垂直视角”数值变化合理，已保存的截图保持不变。
5. 切换到“俯拍 vs 仰拍”，两张快照被清空；再保存两组高度不同的视图，并测试“清空”。
6. 在 Chrome、Safari 和窄屏下测试画面显示、点击反馈与外部 Three.js 模块加载失败时的错误提示。

## 已知边界与后续方向

- 词典搜索是本地小型数据集的即时文本匹配，不涉及全文搜索服务；术语超过数百条后再考虑索引和虚拟化。
- SVG 取景变化是教学示意，真实摄影机视差请在 Three.js 实验室体验；不应把二维裁切误称为真实推轨。
- A/B 截图只来自当前 WebGL 画面（无时间轴），不会自动生成镜头素材，也不提供本地文件导出。
- 截图需保留右侧 WebGL 绘图缓冲区，对显存有额外开销；如后续面向低端手机，再调整为离屏短时捕获。
- 两张并排动画不保证逐帧时间完全同步，当前仅提供独立的动画重播；若要分析同一时刻的物理运动，需要另行设计共享时间轴。
- 这一阶段仍没有真实电影镜头案例；加入影视案例需确保授权，或自制摄影演示。
- 本 PR 的 CI 包含语法、术语结构、搜索逻辑及页面控件的静态检查，**不能代替上述真实浏览器验收**。
