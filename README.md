# Cinematic Lingo · 电影镜头语言可视化词典

一个给零基础电影学习者的交互式电影镜头语言词典：先看动画理解概念，再用摄影机实验室测试真实空间关系。

## 当前内容

| 分区 | 术语数 | 主要演示 |
| --- | ---: | --- |
| 景别 | 8 | 同场景取景范围与景别对比 |
| 机位角度 | 7 | 角度示意、场景动画 |
| 运镜 | 9 | 二维运动动画与轨迹示意 |
| 构图 | 8 | 构图关系与示意 |
| 灯光 | 8 | 光位与明暗效果示意 |
| 转场 | 6 | 剪辑连接方式演示 |

当前共 46 个术语。每张卡片有白话定义、用途、常见情绪效果和易混淆提示。卡片进入视野时会自动播放，点击画面可重播。

## V0.4 · FRAME 电影级视觉美术深化（候选）

V0.3 功能验收通过后，项目建立 **Cinematic Editorial × Architectural Film Set** 视觉体系，不增加额外的学习流程。

- **词典主画面**：将卡通山川插画重绘为原创建筑黄昏取景空间，保留世界坐标、人物比例与 SVG 动画兼容性；摄影图像承载视觉中心，卡片采用专业电影图鉴式编辑排版。
- **实验室主场景**：新增 `js/studio-set.js`，以程序化石材、金属与微纹理混凝土、雕塑化比例人形、暖主光/冷补光/轮廓光与软阴影构成电影摄影测试场景。美术几何与 `js/lab.js` 摄影机数学分离。
- **统一视觉规范**：`art-direction.css` 管理两页石墨、冷灰与低饱和铜色配色、字体层级、镜头视图、UI 控件和响应式布局；不依赖额外字体/图片服务。
- **重点验收**：构图读图、特写人物表现、机位视差、深色对比度、宽屏/手机可用性、WebGL 阴影性能和 Safari 兼容。见 `docs/V0.4_ART_DIRECTION.md`。

V0.4 改动先提交到 Draft PR，不改变已验收的主分支版本。摄影棚人形刻意采用中性的雕塑化替身，旨在标定画幅和空间透视，并非逼真虚拟演员或真实皮肤材质。

**第二轮角色修整**：词典面部用多层解剖光影平面细化；实验室人物拆分为独立 `js/character-maquette.js` 连续网格模块，并改进服装接缝和鞋形。代码修整不是最终高品质角色资产；专业 Blender 网格、UV/PBR 与 GLB 接入规格见 `docs/V0.4_CHARACTER_PRODUCTION.md`。

**可直接开模的设计包**：`docs/V0.4_HERO_ASSET_DESIGN_CH01_SET01.md` 明确 CH-01「静默观察者」及 SET-01「门槛」的轮廓、比例、材料、坐标与验收镜头。视觉概念板仅用来判断气质和光影；建模尺寸应以文档、正交视图和后续灰模验收为准。

## V0.3 · 双板块体验深化（实验分支）

### 可视化词典 · Visual Dictionary

- **即时查找**：中文、英文、缩写和说明文字均可查找。输入后即时过滤六章 46 个术语，`Ctrl/⌘ + K` 快速聚焦，`Enter` 跳到第一个结果，`Esc` 清空搜索。
- **双术语对照**：在任意两张术语卡点击“加入对照”，底部出现对照条；点击“并排观看”，可同时重播两段原始 SVG 动画并阅读定义。再选择第三条术语时会替换 B 项；不需要增加测验功能。
- **保持简洁**：原有卡片、知识标签、点击重播方式都保留。只有用户主动选择对照时才出现底部工具条和对照面板。

### 摄影机实验室 · Camera Lab

- **空间观察**：拖动左侧空间视图旋转，滚轮缩放，点击“重置视角”恢复原位；键盘可使用方向键和 `+/-`。
- **A/B 画面锁定**：选择预设、运行推镜或更改距离/焦距/高度，然后将取景画面“记为 A/B”。两张画面及其参数同时保留在本页，可直接比较遮挡与相对大小；切换实验会清空快照。
- **参数反馈**：右侧显示焦距、距离和由全画幅 24 mm 高度推算的垂直视角。参数改变后依然使用真实 Three.js 相机矩阵。
- **数据限制**：快照只在当前页面内存中保存，不会上传服务器，也不自动下载；刷新页面后消失。为支持画面快照，右侧 WebGL canvas 启用了 drawing buffer 保留，会增加少量显存开销。

本轮仍坚持两个板块，**不增加课程、测验、账户或积分系统**。

### 最低验收清单

1. 在首页输入 `POV` / `特写` / `push` 能得到合理结果；空匹配有提示，清空后恢复全部 46 条词典卡片。
2. 选择两条不同术语，能打开并排对照，两段动画都可点击重播；尤其核对“灯光”条目的渐变动画不受 SVG ID 复制影响。
3. 实验室左侧可以拖动旋转、滚轮缩放、键盘旋转和重置视角，右侧取景不因左侧观察视角改变。
4. 保存 A、调整参数、再保存 B，能同时保留不同的取景画面；切换实验清空历史画面。
5. 桌面和窄屏均能完整操作，原有三组实验与 46 项术语未回归损坏。

> GitHub Actions 验证语法和静态入口；WebGL 绘制、截图正确性与实际动画同步仍需在本地 Chrome/Safari 进行浏览器验收。

## 当前产品结构（V0.2.1）

产品保留两项核心体验：

- **可视化词典**：六大分类、46 个术语；SVG 动画可重播，配有白话解释、常见用途、易混淆提示与简单知识维度标签。
- **3D 摄影机实验室**：双视图实时观察摄影机位置、焦距与透视的关系，包含推镜与变焦、俯拍与仰拍、焦距与透视三组实验。

V0.2 已对全部 46 条术语进行初步审校，修订易误导的绝对化文案；参见 `docs/V0.2_CONTENT_REVIEW.md`。基于试用反馈，V0.2.1 **取消首页概念辨析与答题系统**，不再要求用户完成测验。知识维度标签仅作为词典的辅助信息。项目仍是轻量教学 Demo，不含账号、成绩记录或商业电影素材。

## 摄影机实验室（MVP）

打开 `lab.html`，体验左侧空间视图（相机、人物与前后景）和右侧实时取景：
- 推镜 vs 变焦：从同一机位与焦距分别播放两种运动；最终主体取景尺寸相近，远近景的投影关系不同。
- 高机位 vs 低机位：比较俯拍和仰拍。
- 广角近拍 vs 长焦远拍：认识“焦距改变视角，机位决定透视”。

实验室使用 Three.js，只有这个独立页面需要外部模块；词典保持原生 HTML / CSS / JavaScript + SVG 架构。

## 本地运行

推荐安装 Node.js 18+ 后在仓库根目录运行：

```sh
npx serve . -l 5173
```

然后打开 `http://localhost:5173`（词典）或 `http://localhost:5173/lab.html`（实验室）。

没有 Node.js 时，也可以使用 Python：

```sh
python3 -m http.server 5173
```

注意：实验室从 jsDelivr 加载固定版本的 Three.js，需要网络或浏览器缓存；加载失败时会提示检查网络并刷新。建议不要直接通过 `file://` 打开。词典其余 SVG 资源在仓库内，无视频素材依赖。

## 已知限制
- 原词典运镜主要通过二维 SVG 裁切/变换来辅助理解，不是完整的物理摄影机模型。**尤其不要根据原推拉动画推断真实运动视差。**
- 术语边界与对应情绪并非全行业统一，卡片展示的是教学上的常用解释。
- 实验室是几何简化模型：没有复杂场景、美术资产、镜头畸变、景深与真实光照。
- 教学准确性需要后续结合真实拍摄案例和用户学习测试继续验证。
