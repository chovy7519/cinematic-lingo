# Cinematic Lingo · 电影镜头语言可视化词典

一个给零基础电影学习者的交互式电影镜头语言词典：先看动画理解概念，再用摄影机实验室测试真实空间关系。

| 分区 | 术语数 | 主要演示 |
| --- | ---: | --- |
| 景别 | 8 | 同场景取景范围与景别对比 |
| 机位角度 | 7 | 角度示意、场景动画 |
| 运镜 | 9 | 二维运动动画与轨迹示意 |
| 构图 | 8 | 构图关系与示意 |
| 灯光 | 8 | 光位与明暗效果示意 |
| 转场 | 6 | 剪辑连接方式演示 |

当前共 46 个术语。每张卡片有白话定义、用途、常见情绪效果和易混淆提示。卡片进入视野时会自动播放，点击画面可重播。

## V0.2 · 从术语查阅到概念辨析

- **46 个术语的知识维度标签**：六个浏览章节保留，但每条术语另外标注实际知识领域，例如过肩镜头属于人物关系、主观镜头属于叙事视点、变焦属于光学参数。
- **4 道易混淆概念练习**：推镜/变焦、过肩/POV、摇镜/移镜、柔光/高调，选项即时反馈，含原理解释、相关术语锚点和三维实验链接。
- **术语审校**：修订绝对化判断、二维演示带来的误导与常见光学/剪辑概念错误；“可能的表达”不等于固定情绪公式。
- **审校矩阵**：`docs/V0.2_CONTENT_REVIEW.md` 包含 46 个术语的初步状态、已知限制及参考资料。
- **基础验证**：`node scripts/check-project.mjs` 核验术语总数、46 个标签与练习题链接；GitHub Actions 会执行语法检查。

这仍是教学 Demo：未增加商业电影素材，不涉及账户、分数长期保存，也尚未证明真实学习成效。

## 摄影机实验室（MVP）

打开 `lab.html`，体验左侧空间视图（相机、人物与前后景）和右侧实时取景：
- 推镜 vs 变焦：从同一机位与焦距分别播放两种运动；最终主体取景尺寸相近，远近景的投影关系不同。
- 高机位 vs 低机位：比较俯拍和仰拍。
- 广角近拍 vs 长焦远拍：认识“焦距改变视角，机位决定透视”。

实验室使用 Three.js，只有这个独立页面需要外部模块；词典保持原生 HTML / CSS / JavaScript + SVG 架构。

## 本地运行

推荐安装 Node.js 18+ 后在仓库根目录运行：

```sh
npx serve . -l 5173
```

然后打开 `http://localhost:5173`（词典）或 `http://localhost:5173/lab.html`（实验室）。

没有 Node.js 时，也可以使用 Python：

```sh
python3 -m http.server 5173
```

注意：实验室从 jsDelivr 加载固定版本的 Three.js，需要网络或浏览器缓存；加载失败时会提示检查网络并刷新。建议不要直接通过 `file://` 打开。词典其余 SVG 资源在仓库内，无视频素材依赖。

## 工程结构
- `index.html`：词典首页
- `styles.css`：词典样式
- `js/data/`：术语与教学文案
- `js/demos/`：按分类实现的 SVG 动画
- `js/app.js`、`js/card.js`、`js/section.js`：页面装配、卡片与组件渲染
- `lab.html`、`js/lab-loader.js`、`js/lab.js`：独立三维摄影机实验室及加载错误提示
- `docs/CONTENT_AUDIT.md`：审校记录与科学边界
- `scripts/check-project.mjs`：静态结构校验

## 已知限制
- 原词典运镜主要通过二维 SVG 裁切/变换来辅助理解，不是完整的物理摄影机模型。**尤其不要根据原推拉动画推断真实运动视差。**
- 术语边界与对应情绪并非全行业统一，卡片展示的是教学上的常用解释。
- 实验室是几何简化模型：没有复杂场景、美术资产、镜头畸变、景深与真实光照。
- 教学准确性需要后续结合真实拍摄案例和用户学习测试继续验证。
